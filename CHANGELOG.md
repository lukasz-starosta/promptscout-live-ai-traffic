# Changelog

All notable changes to `promptscout-live-ai-traffic` will be documented here.

This project uses a single repository version for every future published
`@lukasz-starosta/promptscout-live-ai-traffic-*` package. Example workspaces use
the same version for traceability, but remain private and are not published.

## 0.0.0

- Established the initial package, example, and documentation scaffold.
- Added the manual release workflow and release documentation for private
  GitHub Packages, WordPress artifacts, and Docker images if introduced later.
- Kept `0.0.0` as the intentional local-first dogfood version with public npm
  publishing out of scope.
