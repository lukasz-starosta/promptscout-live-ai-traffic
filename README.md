# PromptScout Live AI Traffic

Repository for the PromptScout live AI traffic package and examples.

## Verification

Run the repo-owned verification command before pushing changes:

```bash
./scripts/verify
```

The command is intentionally lightweight while the repository is in its
foundation phase. It checks repository text formatting, shell script syntax,
and the focused verifier tests. See [docs/verification.md](docs/verification.md)
for the full contract and current non-goals.
